## Beta App 描述（zh-Hans，测试者在 TestFlight 里看到）

Zacks Court 把场边的 iPhone 变成发球测速牌和电子司线：1080p / 60 帧本机录像，自动识别球场，估计每次发球的球速，判机位一侧半场的界内外；整段录像和单拍片段都能存到相册。另一台 iPhone 或 Mac 可以做看板，安卓、平板和电脑也能用浏览器看板。机位需要 iPhone 13 或更新机型。没有账号和云服务，数据只存在本机。球速和落点是模型估计，不是测量。

## 本版测试什么（1.1 (9)）

1.1 (9)，在 1.1 (8) 的基础上：
• 界内外回放的结尾改成俯视距离图：球落地后镜头停稳，再升到线的上方，用量尺标出球印离线多少厘米；结论卡挪到顶部，不再挡住球印
• 界内的「约 N 厘米」改成看到的空隙（球印到线的内沿）；压线时写「球印压在边线上」
• 误差画成横跨线的一条带，只有被判的那段线亮起；只回放时标题写 REPLAY，挑战时写 CHALLENGE；App 和浏览器看板画法一致

1.1 (8) 起：机位采集日志与诊断包。1.1 (7) 起：相机负载升高时和发热一样降载。1.1 (6) 起：3D 回放。1.1 (4) 起：挑战。

请重点试：点「回放」看界内外回放，结尾量尺上的数和结论卡对不对得上，俯视画面里球印和线是否清楚；回放如果停在标题上或中途消失，请反馈。也请照常看：机位多久认出球场，认不出时照样录 30 秒以上，再把「导出 › 诊断包」和录像发回；发球球速和近端界内外是否合理；录像和单拍片段能否存到相册。

每次合入 PR 后都从新的 main 打一个构建，推给内测组和公测组（2026-11-04 起），这一节随之改写。
