## Beta App 描述（zh-Hans，测试者在 TestFlight 里看到）

Zacks Court 把场边的 iPhone 变成发球测速牌和电子司线：1080p / 60 帧本机录像，自动识别球场，估计每次发球的球速，判机位一侧半场的界内外；整段录像和单拍片段都能存到相册。另一台 iPhone 或 Mac 可以做看板，安卓、平板和电脑也能用浏览器看板。机位需要 iPhone 13 或更新机型。没有账号和云服务，数据只存在本机。球速和落点是模型估计，不是测量。

## 本版测试什么（1.1 (10)）

1.1 (10)，在 1.1 (9) 的基础上：
• 手持拍摄或机位被碰后，画面离开了球的背景就重建背景，不再把整片画面的变化当成一拍；画面一直在动时不记击球
• 某一拍的数值算坏时只把那一项写成「—」，记录照常保存，不再提示「记录保存失败」
• 用自研模型时，模型已经就绪就不再误报「模型尚未就绪」；记录详情里的离线补算写明自研模型还不支持

1.1 (9) 起：回放结尾的俯视距离图。1.1 (8) 起：机位采集日志与诊断包。1.1 (7) 起：相机负载升高时和发热一样降载。1.1 (6) 起：3D 回放。1.1 (4) 起：挑战。

请重点试：机位架稳（三脚架或靠住），对着球场或屏幕上的比赛录一段，看没有击球时拍数会不会自己涨；再拿在手里晃一晃，晃的时候拍数不应增加。如果仍有凭空多出的拍或「记录保存失败」，请把这次记录的「导出 › 诊断包」和录像发回。也请照常看：机位多久认出球场，发球球速和近端界内外是否合理，录像和单拍片段能否存到相册。

每次合入 PR 后都从新的 main 打一个构建，推给内测组和公测组（2026-11-04 起），这一节随之改写。
