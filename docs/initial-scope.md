# 初版范围与后续规划

2026-10-26 项目已调整为 **Mac / iPhone 共用、可选择客户端或服务端的统一 App**。当前产品与技术决策以 [统一 App 规划](unified-app.md) 为准。

最初“iPhone采集、Mac接收”的原型保留了H.264、TLS配对、来源时间戳、MOV和双端录像基础；设备角色限制与两套独立工作台已移除。旧里程碑的测试证据保留在 [验证记录](verification.md)。

2026-10-26 用户进一步明确核心为测速、落点、动作分类，取消计分。此前人员看板与手动比分方案已被替换。当前主线为真实 Core ML 时序推理、球场标定、每拍球速/落点候选、动作分布和对应视频回看；人员检测仅作辅助。历史验证记录保留其当时范围，不表示旧产品优先级仍有效。
